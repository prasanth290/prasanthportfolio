# Prasanth Custom Web Studio & Portfolio

A premium freelance web development studio and portfolio website built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Prisma ORM**.

## Features

- **Proof-First Case Studies**: Showcasing real completed business applications (Rental Management Systems, Inventory Control Suites).
- **Interactive Sandbox Demos**: Live working deployments with copyable demo login credentials.
- **Interactive Estimator Widget**: Instant budget and timeline estimation for custom web app builds.
- **Single-Admin Portal**: Complete admin panel for managing projects, gallery screenshots, leads inbox, and site settings.

## Getting Started

```bash
# Install dependencies
npm install

# Run database setup & seed
npx prisma db push
npx tsx prisma/seed.ts

# Launch local development server
npm run dev
```

Admin Login: `/admin/login` (`admin@devstudio.com` / `admin123`)
